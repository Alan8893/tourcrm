# TourCRM

CRM и информационная система школьного туристского клуба.

## Назначение

TourCRM предназначен для управления участниками клуба, родителями и инструкторами, учебным процессом, мероприятиями, походной деятельностью, достижениями, документами, финансами, снаряжением и связанными коммуникациями.

## Статус проекта

Проект находится на стадии формирования требований и архитектуры. Реализация выполняется по GitHub Issues.

## Основные принципы разработки

1. Каждая единица работы оформляется как GitHub Issue.
2. Работа выполняется последовательно: анализ Issue → реализация → автоматическое тестирование → проверка → закрытие Issue.
3. Issue не закрывается, пока критерии приёмки не выполнены и автоматические проверки не прошли.
4. Архитектурные решения фиксируются документально.
5. Изменения требований должны отражаться в документации и связанных Issue.
6. Работа с персональными данными выполняется с учётом требований безопасности и применимого законодательства.

## Предварительная архитектурная модель

Проект предполагает адаптивное web-приложение, работающее на ПК, планшетах и мобильных устройствах, с возможностью работы через локальную сеть и через интернет.

Предварительно рассматриваются:

- frontend web-приложения;
- backend API;
- PostgreSQL;
- Redis при необходимости;
- Docker;
- Linux;
- reverse proxy;
- CI/CD через GitHub Actions;
- резервное копирование и мониторинг.

## Основные домены

- аутентификация и авторизация;
- пользователи и роли;
- участники клуба;
- родители и законные представители;
- группы;
- расписание и мероприятия;
- посещаемость;
- походы и туристский опыт;
- маршруты и GPX;
- достижения и рейтинг;
- база знаний;
- документы;
- финансы;
- снаряжение;
- уведомления и коммуникации;
- турслёты и внешние интеграции;
- аудит действий;
- аналитика и отчётность.
