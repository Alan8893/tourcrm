# ADR-0007: Background processing

## Статус
Accepted

## Решение

Синхронный HTTP request используется для операций, которые должны дать пользователю быстрый детерминированный ответ.

Фоновые задачи применяются для:

- отправки email/Telegram/MAX notifications;
- retry внешних доставок;
- обработки больших файлов и GPX;
- генерации тяжёлых отчётов;
- периодических housekeeping jobs;
- пересчёта производных статистик, если операция превышает допустимое время HTTP request;
- других длительных или повторяемых операций.

Redis используется как broker/cache только там, где наличие отдельной очереди оправдано. Конкретная библиотека worker queue фиксируется перед реализацией.

Все background jobs должны быть:

- idempotent, где это возможно;
- retry-safe;
- наблюдаемыми;
- с ограничением числа попыток;
- с dead-letter/error state там, где потеря задачи недопустима.

## MVP

Redis не должен становиться обязательной зависимостью для простых synchronous CRUD use cases.
