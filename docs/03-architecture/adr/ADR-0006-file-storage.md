# ADR-0006: Хранение файлов и геоданных

## Статус
Accepted

## Решение

Файлы (документы, фотографии, GPX, вложения базы знаний и другие binary objects) не являются частью PostgreSQL data model как основной способ хранения.

Приложение использует storage abstraction с разделением:

- metadata и ownership — PostgreSQL;
- binary content — object/file storage.

Каждый объект должен иметь контролируемый идентификатор, MIME/content type, размер, checksum, владельца/связь с доменной сущностью, статус и timestamps.

Доступ к приватным файлам осуществляется через application authorization, а не через публичные постоянные URL.

## Причины

- БД не разрастается из-за binary data;
- проще делать backup и перенос;
- можно заменить локальное хранилище на S3-compatible/VPS storage без изменения доменных модулей;
- проще управлять большими файлами и GPX.

## MVP

На первом этапе допускается локальное файловое/object storage на сервере, но интерфейс доступа должен быть абстрагирован.

## Безопасность

Проверяются размер, MIME/type, расширение, checksum и права доступа. Пользовательский filename не используется как единственный идентификатор хранения.
