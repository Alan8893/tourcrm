# Brand package

## Official master

The Brand package currently contains **one approved master asset**:

```text
docs/06-ui/assets/packages/brand/logo.png
```

This PNG is the official TourCRM / «Вектор» logo master and is the single source of truth for the brand mark in this asset hand-off.

## Production rules

- PNG master only.
- SVG is not used for TourCRM production UI assets.
- No ZIP archive is required for this Brand hand-off.
- No artificial `primary`, `horizontal`, `compact`, `light`, `dark`, `monochrome`, `favicon` or `app-icon` variants are created at this stage.
- Technical derivatives may be produced later only when a concrete product need is approved, using this master as the source.
- The official master must not be redrawn, replaced or stylistically altered without explicit visual approval.

See `../../ASSET-PACKS.md` and `../../ASSET-STATUS.md` for registry and lifecycle status.
