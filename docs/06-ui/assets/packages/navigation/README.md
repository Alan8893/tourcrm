# Navigation package

Approved TourCRM Navigation visual assets. Binary package: `TourCRM_Visual_Assets_v1.0_FINAL.zip`.

Contains 7 custom navigation icons in raster WebP at 16, 20, 24, 32, 48 and 64 px, plus PNG raster masters and the approved navigation sheet.

The superseded `TourCRM_Assets_Navigation_P0.zip` package was removed from this directory and must not be used.

The package contains no SVG assets.
