# Navigation package

## Status: CLOSED / APPROVED

The TourCRM Navigation visual system is fully agreed and must be treated as **closed**. Do not reopen, redesign, replace or regenerate these navigation assets during the current visual-foundation work unless the Product Owner explicitly requests a Navigation change.

### Approved navigation

The fixed navigation set contains exactly 7 items:

1. Home
2. People
3. Groups
4. Events
5. Achievements
6. Reports
7. Settings

The approved custom artwork is the visual source of truth. The `Home` artwork is the approved reference for the TourCRM custom icon language. `Settings` uses the approved compass + wrench artwork.

### Production package

Binary package: `TourCRM_Visual_Assets_v1.0_FINAL.zip`.

Contains 7 custom navigation icons in raster WebP at 16, 20, 24, 32, 48 and 64 px, plus PNG raster masters and the approved navigation sheet.

The package contains no SVG assets.

The superseded `TourCRM_Assets_Navigation_P0.zip` package was removed from this directory and must not be used or referenced.

### Change control

Navigation is considered complete for this asset-production stage. Future work must use the approved package as-is. Any change to the navigation catalog, artwork or semantics requires an explicit Product Owner decision and a separate documented change; it must not be introduced implicitly while working on other asset families.
