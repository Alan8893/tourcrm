# TourCRM UI — Navigation P0 WebP Pack

Status: **Approved / uploaded**

## Approved set

The P0 navigation set consists of seven custom TourCRM navigation artworks:

- `icon.navigation.home`
- `icon.navigation.people`
- `icon.navigation.groups`
- `icon.navigation.events`
- `icon.navigation.achievements`
- `icon.navigation.reports`
- `icon.navigation.settings`

## Delivery format

Primary delivery format: **WebP with transparent background**.

Production raster sizes:

`16 / 20 / 24 / 32 / 48 / 64 px`

PNG high-resolution raster masters are included in the visual handoff package for preservation and refinement purposes.

The approved Settings artwork uses a compass with a wrench replacing the compass needle.

## Design rule

These are authored TourCRM visual assets, not generic icon-library replacements. The artwork retains the approved sticker/illustration character, expressive outlines, saturated layered color and recognizable outdoor/adventure motifs.

SVG is not used for TourCRM production UI assets.
